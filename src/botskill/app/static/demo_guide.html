Step-by-Step System Manual

Everything you need to know to download, configure, run, test, and upgrade BOTSKILL.

1. Launch & Prerequisites

Ensure Python 3.12 is installed and Microsoft Outlook is open on your machine. Double-click the launcher batch file:

.\run_botskill.bat

Automatically bootstraps directories, runs SQLite crash recovery, and opens the loopback workstation on port 8765.

2. "Training" on Policies

Upload company policies, handbooks, and SLAs (PDF, DOCX, TXT, CSV). Candidate rules are extracted with citations:

python -m botskill.cli policy list
python -m botskill.cli policy approve <rule_id>

Human approval is mandatory. Inactive rules cannot be used by the AI to make commitments.

3. Testing & Upgrades

Run the comprehensive 69-test suite anytime to ensure zero regressions across unit, integration, and E2E tests:

python -m pytest -v

Source code is protected by an anti-tamper guard. Update rules by uploading new policy documents without modifying code.
